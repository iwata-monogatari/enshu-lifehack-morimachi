#   その他の個別拒否設定と /admin/ の制限は維持する。

# 注意: robots.txt は user-agent ごとに「最も限定的な1グループだけ」が適用され、
#   自分専用のグループがあると User-agent: * のルールは無視される。
#   そのため個別グループにも Disallow: /admin/ を書く必要がある。
#   (以前は Googlebot / Bingbot に書き忘れており、両者だけ /admin/ を
#    クロールできる状態になっていた。2026-08-04に修正)

# --- 編集憲章に基づく Google-Extended の許可 ------------------------------
# Google-Extended は「Geminiの学習」と「Geminiのグラウンディング(回答時の参照)」を
# まとめて制御するトークンで、両者を分けられない。
#   拒否したまま  -> 学習に使われない代わりに、Geminiの回答で引用されない
#   許可に変える  -> Geminiに引用され得るが、学習にも使われる
# Google検索の順位・インデックスには**どちらでも影響しない**
# (出典: developers.google.com/search/docs/crawling-indexing/google-common-crawlers)
# 2026-09-21: 編集憲章 §6.4 の指定に合わせて許可。
User-agent: Google-Extended
Allow: /
Disallow: /admin/
