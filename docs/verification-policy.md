# 情報確認ポリシー（森町ライフハック）

制定 2026-08-05 ／ 対象: `/life/` 配下の全記事と、公開している固定ページ

## 1. 「最終確認日」の意味

画面に出す「最終確認日」は、**公式リンクを開いた日ではない**。
次のすべてを確認した日だけを最終確認日として表示する。

- 窓口名
- 電話番号
- 受付時間
- 費用
- 対象者
- 期限
- 必要書類
- 公式リンクが開くこと
- 国の制度と自治体案内に矛盾がないこと
- 「予定」「今年度」など時点に依存する表現が現在も正しいこと

一部だけ確認した場合は、最終確認日を更新しない。

## 2. 確認状態（review_status）

`data/article-ledger.json` / `reports/morimachi-pages-ledger.csv` で管理する。

| 値 | 意味 | 画面表示 |
|---|---|---|
| `verified` | 上記1をすべて一次情報で確認済み | 最終確認日を表示してよい |
| `partial` | 一部のみ確認、電話確認待ち、国と自治体で記載が食い違う | 差の理由をページに書く。トップの「確認済み」に数えない |
| `needs_review` | 確認期限切れ、または一次情報が未確認 | 確認済みとして数えない |
| `archived` | 制度終了・記事廃止 | 検索対象から外すか、旧制度である旨を注記 |

トップページの件数は台帳から自動集計する。HTMLに直接書かない。

## 3. リスク区分と見直し頻度

| リスク | 対象 | 見直し |
|---|---|---|
| A | 救急・医療・法律・税・死亡・期限・給付 | 3か月ごと。重大変更時は即時 |
| B | 受付時間・料金・電話番号・ごみ・施設運用 | 6か月ごと |
| C | 公園・文化・地域紹介 | 12か月ごと |

期限を過ぎたページは `build_article_ledger.py` が `needs_review` に落とし、
`review_overdue` 列で警告する。

## 4. 出典の優先順位

1. 法令・e-Gov・国の所管省庁
2. 静岡県の公式情報
3. 森町公式情報
4. 公立森町病院・消防・医師会等の公式情報
5. 電話確認
6. その他の二次情報

**町公式ページが古く、国制度と矛盾する場合は、町公式を無条件に優先しない。**
差がある場合は、両方を確認したうえで、画面に差の存在と確認日を書く。

### 実例（2026-08-05）

- 死亡届の押印
  法務省は戸籍届書の押印義務を2021年9月1日に廃止（任意）。
  森町公式の死亡届ページは更新日2020-02-25で「届出人の印鑑」の記載が残る。
  → 本文は「署名。押印は任意」とし、町公式に古い記載がある旨を注記。
  電話確認は未実施のため `partial`。

- 森町ちゃっとメール
  森町公式（更新日2021-02-01）に「令和8年3月で終了」。その時期は経過済みだが、
  実際に終了したかはページから判断できない。
  → 「終了と案内されており、その時期は過ぎている」と書き、`partial`。

## 5. 自治体固有語

`data/city.json` の `municipality` ブロックが唯一の根拠。
テンプレートに「市役所」等を直接書かない。森町は町であり、庁舎は森町役場。

「市役所」は検索する人がいるため、**検索辞書（synonyms）には残してよい**。
画面表示に使ってはならない。

## 6. 公開前に必ず通すもの

```
python scripts/build_all.py      # 生成→注入→SEO→索引→検査
```

`scripts/preflight_check.py` が次を検査し、1件でも該当すれば公開を止める。

- 内部リンク・アンカー切れ
- 301の対応表と `_redirects` の不一致
- canonical / title / description / H1 の欠落と重複
- 構造化データ（BreadcrumbList、トップの WebSite/Organization/SearchAction）
- FAQ構造化データと画面表示の不一致
- 画面上の内部キー露出
- 意味が途中で切れるリンク文言
- 緊急・医療・生活困窮ページの営業CTA、開示文の欠落
- sitemap の実在性・重複・リダイレクト混入
- 寺院・神社の件数整合
- 「市役所」テンプレート残り、戸籍届書の押印必須表現、リンク内の重複表示
- 空見出し・空セクション
- すでに過ぎた日付の「予定」表現
- canonical・og:url・サイトマップへのパラメータ混入

公開後は必ず次を実行する。

```
python scripts/verify_published.py
```
