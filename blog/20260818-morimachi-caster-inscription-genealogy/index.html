鋳物師銘文系譜表で解く問い

森町公式資料には「近世を通じ、遠江・駿河両国の鋳物師(いもじ)を支配したのが森町村の山田七郎左衛門家であった。」と記されています。森町の鋳物師を銘文・製作年・奉納先でつなぐでは、この記載を鋳物師銘文系譜表の一行にし、作者名、銘文、制作物、奉納先、年代根拠を結び直すための根拠として扱います。資料名と確認日を先に書き、後から説明だけが独り歩きしないようにします。

同じページで確認できる「この他、栄泉寺・大洞院・可睡斎など各地の寺院に残る 梵鐘 ( ぼんしょう ) が鋳物師の活動を物語っている。」は、前の事実と似ていても別の対象です。鋳型・梵鐘・銘文を読み解くときは、資料の掲載順ではなく、名称・年代・場所・根拠の対応を見ます。写真、家族の記憶、公的資料を三列に分け、食い違いを未確認として残します。

鋳物師銘文系譜表では「山田七郎左衛門は、1587年(天正15年)、小牧の陣従軍などの功績により、徳川家康から「 駿遠 ( すんえん ) 両国鋳物師惣大工職」の朱印状を与えられた。」の確認欄と「幕末期、山田氏は、森町などの知行主であった土屋氏の用達金などを賄い、また陣屋の代官に登用されるなど、鋳物師以外の活躍も大きい。」の照会欄を分けます。公式本文が述べていない現況や公開可否は未確認と書き、家族の記憶には話者と聞取日を添えます。旧記録を消さず、回答日と確認先を付けた新しい行を追加します。

よくある質問

鋳物師銘文系譜表で最初に書く項目は何ですか。

資料名、対象名、確認日、根拠の種類です。作者名、銘文、制作物、奉納先、年代根拠を結び直すため、現況と家族の記憶は別欄にします。

鋳物師銘文系譜表に所在地があれば現地を見学できますか。

掲載だけでは判断できません。近世を通じ、遠江・駿河両国の鋳物師(いもじ)を支配したのが森町村の山田七郎左衛門家であった。という記録は鋳型・梵鐘・銘文を読む根拠ですが、現在の公開日時や立入り条件の根拠ではありません。対象ごとに管理者の案内を確認します。

鋳物師銘文系譜表で年代が複数ある場合はどれを採用しますか。

山田七郎左衛門は、1587年(天正15年)、小牧の陣従軍などの功績により、徳川家康から「 駿遠 ( すんえん ) 両国鋳物師惣大工職」の朱印状を与えられた。という記録を起点に、鋳型・梵鐘・銘文の制作、記録、移転、発見などの動作を分けます。異なる出来事の年は統合せず、それぞれの典拠を同じ行に残します。

家族の記憶は鋳物師銘文系譜表の公式事実と一緒に書けますか。

幕藩体制成立後、平和な時代の到来とともに、鋳物氏の経営にも大きな変化が現れる。という公的記載とは別欄にします。鋳型・梵鐘・銘文について話した人、聞取日、確信度を書けば、家族の記憶を残しつつ公的資料へ上書きせず比較できます。
