🧭 粗大ごみの持ち込み先と費用を知る

軽トラックが無くても持ち込めますか

静岡県周智郡森町で「粗大ごみの持ち込み先と費用を知る」ときに、最初に確認したい答えをまとめました。

先に結論

回答

自家用車でも搬入できますが、積める量には限りがあります。量が多い場合は複数回に分けるか、レンタカーの利用も検討してください。詳しくは中遠広域粗大ごみ処理施設（0538-37-4854）にご確認ください。

この回答の前提

森町では粗大ごみの戸別収集は行っておらず、中遠広域粗大ごみ処理施設（磐田市新貝）への直接搬入が基本です。事前に品目と搬入時間を確認してから運びましょう。

手数料は車両の最大積載量により520円～2,090円です。処分に迷う不用品は、ジモティー経由の中遠クリーンセンターリユーズ事業（無料）も検討できます。

先に確認したいこと

🚗 直接搬入が基本

戸別収集の案内は見当たらず、中遠広域粗大ごみ処理施設（磐田市新貝59-1）へ自分で運び込むのが基本の流れです。平日9:00-12:00・13:00-16:30の受付時間に注意してください。

💰 料金は積載量で決まる

手数料は車両の最大積載量に応じて520円～2,090円です。事前に電話（0538-37-4854）で搬入可能な品目と料金を確認しておくと当日慌てません。

♻️ 無料で譲る手も

まだ使える家具や家電は、中遠クリーンセンターがジモティーに出品するリユーズ事業で無料譲渡できる場合があります。捨てる前に一度検討してみましょう。

確認の順番

  1. 今日確認する処分したい粗大ごみの品目をリストアップする
  2. 今日確認する中遠広域粗大ごみ処理施設に電話して受入可否と料金を確認する
  3. 次に進める搬入日時を決めて車を用意する
  4. 次に進める平日9:00-12:00・13:00-16:30の間に施設へ搬入する
  5. 家族・関係先と確認するまだ使えるものはジモティーでの無料譲渡を検討する
  6. 家族・関係先と確認する分別に迷うものは住民生活課生活環境係に相談する
